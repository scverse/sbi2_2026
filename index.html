Deep learning on morphology data within the scverse ecosystem

scverse x SBI2 2026

Monday, November 2, 2026, 13:00 - 15:00 · Boston, MA, USA

A two-hour hands-on workshop on storing single-cell morphology data in AnnData, training models on it with annbatch, and using pretrained image models.

About the event

scverse x SBI2 2026

This workshop shows how to work with single-cell morphology data from Cell Painting screens in the scverse ecosystem, and how to train and use deep learning models on it. We use single cells from the JUMP Cell Painting TARGET2 plates, with features measured by cp_measure and image crops of every cell, all stored together in one AnnData object.

The workshop pairs short introductions with hands-on notebooks. Models that take hours to train were trained in advance, so every step runs on a laptop in a few minutes.

What you will take away

  • How to store per-cell features, images and embeddings of a screen in AnnData, and why a single-cell table is the starting point for deep learning.
  • How to train a model on AnnData with annbatch, in memory on a laptop and streamed from disk for millions of cells.
  • How to run a pretrained image model (OpenPhenom) on single-cell crops, and how a fine-tuned model compares.
  • How to judge a representation by how well it separates compounds from controls, and why too few controls make hand-designed features call inactive compounds active.

Bring your own laptop. Everything runs locally. Please follow the setup instructions before the workshop, including the data download.

Setup

Everything in this workshop runs on your own laptop, without a GPU. You install one environment, register it as one Jupyter kernel, and download one data file. Please do this before the workshop, because the conference wifi will not handle everyone downloading at once.

Each step ends with a check you can run.
